# Server Diagnostics Jenkins Pipeline

Jenkins Pipeline для автоматической диагностики удалённого Linux-сервера.

Pipeline выполняет сетевые проверки со стороны Jenkins Agent, затем подключается к целевому серверу по SSH и собирает информацию о состоянии сервиса, процессах, ресурсах и доступности приложения.

В конце формируется единый диагностический отчёт `diagnostic-report.txt`, который архивируется как Jenkins Artifact.

---

## Возможности

Pipeline выполняет следующие проверки:

### Network Diagnostics

Проверки выполняются со стороны Jenkins Agent:

- `ping` — проверка ICMP-доступности сервера
- TCP port check — проверка доступности указанного TCP-порта
- HTTP check — проверка HTTP-доступности сервиса
- `traceroute` / `tracepath` — диагностика маршрута до сервера
- `mtr` — диагностика маршрута и потерь пакетов

---

### Server Diagnostics

После сетевых проверок Pipeline подключается к серверу по SSH и собирает информацию о самом сервере.

Проверяется:

- hostname
- uptime
- состояние systemd-сервиса
- включён ли сервис в автозагрузке
- `systemctl status`
- последние 50 записей журнала сервиса через `journalctl`
- Main PID сервиса
- дочерние процессы сервиса
- процессы с наибольшей загрузкой CPU
- прослушиваемые TCP-порты
- использование оперативной памяти
- использование дискового пространства
- наличие OOM-событий
- локальная HTTP-доступность сервиса через `127.0.0.1`
